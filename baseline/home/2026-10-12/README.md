# Експорт текстів головної сторінки Tur.ai

Пакет для передачі агенту, який перепише контент у межах чинної верстки. **228 текстових полів** із поточними значеннями, кількістю символів, індивідуальними лімітами та прив’язками Webflow. Контент і публікацію сайту під час підготовки не змінювали.

## Що передати агенту

Передай весь ZIP. Порядок читання:

1. `00_BRIEF_FOR_AGENT.md` — повне завдання, правила лімітів, виділень, форм, повторів і приймання макета.
2. `03_FACTS_AND_DUPLICATES.md` — числові твердження, розбіжності та групи текстів, які треба узгодити.
3. `01_FULL_CONTENT_EXPORT.md` — усі поточні тексти в порядку секцій із лімітами й прив’язками.
4. `02_REWRITE_TEMPLATE.json` — заповнюваний результат по кожному ID.

`index.html` — зручний локальний перегляд із пошуком; він не відтворює макет сайту. `inventory.json` — повний машинний інвентар. `validate_rewrite.py` перевіряє ID, символи й сегменти готової редакції. `evidence/` містить вихідне дерево, компоненти, метадані, DOM-виміри на 1383/820/667/393/320 px і два контрольні скриншоти. `QA_COUNTS.json` та `QA_REPORT.md` описують перевірку повноти.

## Що означають ліміти

Максимум у кожному полі дорівнює поточній нормалізованій довжині. Бажаний діапазон дає запас для редагування. **Однакова кількість символів не гарантує однакової ширини або кількості рядків.** Після заміни потрібне візуальне порівняння в Webflow на всіх контрольних ширинах і в прихованих інтерактивних станах.
