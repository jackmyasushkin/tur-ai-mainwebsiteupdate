У GitHub робочі гілки поки потрібно зберегти: прийнята реалізація ще не потрапила в `main`. Цей список не є дозволом на видалення або публікацію.

Усі три URL повернули **HTTP 200**. На перевірених актуальних статичних сторінках не знайдено посилань на ці три адреси. Між старими копіями є чотири посилання на `/old-home`: три з Home EN Copy, одне з Home test. Це підстава розглядати старі сторінки як одну групу для прибирання.

Перевірка посилань охопила 13 статичних адрес із переліку сторінок. CMS-статті, посилання, створювані під час виконання JavaScript, налаштовані перенаправлення, зовнішні кампанії та відвідуваність залишаються умовами остаточного рішення. HTTP 200 не доводить, що сторінкою хтось користується; відсутність внутрішніх посилань не доводить відсутності зовнішніх.

Цей висновок стосується **пісочниці**, Site ID `6899ffe04a85e00f2b8cf5ab`. Він не є інвентаризацією іншого Webflow-сайту або основного домену.

## Що зберегти у Webflow

- **Home** `/` — актуальна прийнята сторінка, Page ID `6899ffe04a85e00f2b8cf5ac`.
- **Home UA** — окрема мовна версія, зараз у draft; завершення English Home не робить її зайвою.
- **Style Guide** — джерело стилів, зараз у draft.
- Три сторінки кейсів, чотири юридичні сторінки EN/UA та **Articles Template** — окремі матеріали й CMS-шаблон.
- Визначення компонентів, стилі, активи й інтеграції форм, які використовуються іншими сторінками. Не виконувати глобальне «очищення невикористаного» разом із видаленням старих Home.
- Зареєстрований `turaihomeordinalformatterissue3` версії `1.0.0` та чотири маркери ordinal у поточній Home — це активне прийняте виправлення анімації.

## Матеріали репозиторію

`content/home/local-precheck.json` — старий звіт редакції v1. Його можна перенести в історичний архів після оновлення посилання в `docs/IMPLEMENTATION_HANDOFF.md`; поточний пакет уже прямо позначає його як застарілий. Видалення не обов'язкове й дасть мінімальний виграш.

`docs/NEXT_AGENT.md` варто актуалізувати окремо: він досі описує початок уже виконаного перенесення. Файл потрібен як точка входу, тому рекомендація — оновити, а не видалити.

Зберегти `baseline/`, усі три датовані папки `implementation/`, їхні MANIFEST, журнали, знімки до/після, рішення, точний набір текстів, джерело ordinal-скрипта й QA. Це історія відновлення та доказ приймання. Старі пропозиції всередині цих папок не є чинним планом, але їхнє вибіркове видалення зламає зафіксовані контрольні суми або втратить контекст рішення.

Локальний `tools/__pycache__/` можна прибрати як відновлюваний кеш. Він не відстежується Git і не є проміжною версією сайту.
